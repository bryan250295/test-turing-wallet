TBC Oracle 价格预言机

钱包里的一笔 TBC 折合多少美元？即使 TBC 对 USDT 的价格没动，只要 USDT 对美元的汇率变了，这笔余额的美元估值也会变。TBC Oracle 把多个交易市场的行情整理成带数字签名的参考价。钱包和行情看板可以在演练环境中用它展示估值，让用户看到每笔估值采用的行情和汇率。

四种参考报价

报价 可以查到什么
BTC/USD 一枚比特币的美元参考价
TBC/USDT 一枚 TBC 折合多少 USDT
USDT/USD 一枚 USDT 的美元参考价
TBC/USD 由 TBC/USDT 和 USDT/USD 换算出的一枚 TBC 的美元参考价

市场行情如何变成参考价

以 BTC/USD 为例，预言机先检查 Coinbase、Kraken 和 Bitstamp 各自的行情。买卖双方的报价相差多大？接近当前价格的挂单有多少？最近是否还有成交？这些检查有助于识别交易稀少或更新滞后的行情。三家行情都合格、价格差异也在设定范围内时，系统把各市场的买卖中间价从低到高排列，取居中的一个作为参考价。

TBC/USDT 还支持按固定权重汇总三个市场的中间价，其中 Hyperliquid 占 50%，LBank 占 40%，MEXC 占 10%。Hyperliquid 以 USDC 计价，系统先用 Kraken 的 USDC/USDT 汇率换算，再把三个价格加权。启用这套配置时，只要任一必要来源失效，TBC/USDT 和依赖它的 TBC/USD 就会暂停报价。

TBC 的美元价怎么算

假设行情　若 1 TBC 值 2.00 USDT，1 USDT 值 0.99 美元，换算后 1 TBC 值 1.98 美元。

假设钱包里有 100 TBC 和 20 USDT。按上面的行情，两笔余额分别值 198.00 美元和 19.80 美元，合计 217.80 美元。钱包只需请求一次估值快照，就能同时拿到 TBC/USD 和它引用的两份基础报价。这样，两笔余额用的是同一份 USDT 汇率，用户也能按原数复算总额。

报价验证与使用

怎样判断一份报价还能不能用

核对是谁签发的。 当前版本由单节点签发报价。应用通过独立可信渠道取得报价公钥，就能验证报告的数字签名。如果有人改动价格、轮次或有效期，签名校验就会失败。

读懂报告上的三个时间。 观察时间说明这份价格依据的是何时的行情，签发时间说明预言机何时签署报告，到期时间给出使用期限。即使刚收到报告，也应按行情的观察时间判断新鲜度。两份基础报价中只要有一份到期，应用就要停用这轮 TBC/USD。

使用前检查在线状态。 例如，钱包刚收到快照，预言机随后检测到一个必要行情源断连。即使报告尚在有效期内，这次在线检查也会提示报价不可用。钱包可以暂时显示“参考价暂不可用”。待相关行情连续五分钟通过质量检查、服务恢复后，再获取新快照更新估值。

怎样回查一次估值

如果用户想核对昨天看到的余额，钱包可以凭当时保存的币对和报价轮次，调出原始签名报告与对应的证据摘要。TBC/USD 报告还记录了它采用的两份基础报价的轮次。结合当时的持仓数量，就能重算那次美元估值。需要了解报价的链上发布进度时，还可以查询交易 ID 和确认数。

如何体验

当前版本适合在独立环境中试做钱包估值、行情展示和历史查询。真实市场准入、七天校准及随后的十四天报价观察仍待完成，当前版本不能用于真实抵押、借款或清算。

首次体验可从示例中的钱包余额开始。向部署负责人获取演练环境的 HTTPS 地址和 CA 证书，通过独立可信渠道取得验签配置，再按手册查询一份 TBC/USD 快照，验证签名，并用返回的两份基础报价算一遍美元价。具体步骤见部署包内的《报价 API 使用手册》。

TBC Oracle Price Oracle

How much is the TBC in your wallet worth in US dollars? Even if the TBC/USDT price stays unchanged, the dollar value of your holdings changes when the USDT/USD exchange rate moves. TBC Oracle aggregates market data from multiple trading venues into digitally signed reference prices. In a test environment, wallets and market dashboards can use these prices to display valuations and show users which market quotes and exchange rates were used.

Four Reference Price Pairs

Price pair What it tells you
BTC/USD Reference price of one bitcoin in US dollars
TBC/USDT How many USDT one TBC is worth
USDT/USD Reference dollar value of one USDT
TBC/USD Reference dollar value of one TBC, calculated from TBC/USDT and USDT/USD

How Market Data Becomes a Reference Price

Take BTC/USD as an example. The oracle first examines market data from Coinbase, Kraken, and Bitstamp. How wide is the spread between bids and asks? How much order-book liquidity is available near the current price? Have trades occurred recently? These checks help identify thinly traded or stale markets. When all three venues pass the checks and their prices fall within the configured deviation range, the system sorts their bid–ask midpoints and selects the median as the reference price.

TBC/USDT also supports a fixed-weight aggregation of mid-market prices from three venues: Hyperliquid at 50%, LBank at 40%, and MEXC at 10%. Because Hyperliquid quotes in USDC, the system first converts its price using Kraken's USDC/USDT exchange rate, then computes the weighted average. When this configuration is enabled, a failure of any required source suspends both TBC/USDT and the dependent TBC/USD quote.

How Is the Dollar Price of TBC Calculated?

Illustrative market prices: If 1 TBC is worth 2.00 USDT and 1 USDT is worth US$0.99, then 1 TBC is worth US$1.98.

Suppose a wallet holds 100 TBC and 20 USDT. At those prices, the balances are worth US$198.00 and US$19.80 respectively, for a combined value of US$217.80. With a single valuation-snapshot request, the wallet receives TBC/USD along with the two underlying quotes it references. Both balances therefore use the same USDT exchange rate, and the user can independently reproduce the total from the original figures.

Quote Verification & Usage

How Can You Tell Whether a Quote Is Still Usable?

Verify who signed it. In the current version, a single node signs price reports. An application can verify the digital signature using the oracle's public verification key, obtained through an independent, trusted channel. Any alteration to the price, round number, or validity period will cause signature verification to fail.

Understand the three timestamps in the report. The observation time indicates when the underlying market data was observed; the issuance time indicates when the oracle signed the report; and the expiration time defines how long it remains valid. Even if a report has just arrived, its freshness should be judged by the observation time. If either underlying quote has expired, the application must stop using that round of TBC/USD.

Check live availability before use. For example, a wallet might receive a snapshot just before the oracle detects that a required market feed has disconnected. Even if the signed report has not expired, a live status check will flag the quote as unavailable. The wallet can temporarily display “Reference price unavailable.” Once the affected market feeds have continuously passed quality checks for five minutes and the service has recovered, the wallet can request a fresh snapshot to update its valuations.

How to Audit a Past Valuation

If a user wants to verify a wallet balance shown yesterday, the wallet can use the saved trading pair and quote round to retrieve the original signed report and its corresponding evidence summary. A TBC/USD report also records the round numbers of its two underlying quotes. Together with the holdings at that time, this information allows the dollar valuation to be recalculated. To inspect the on-chain publication progress of a quote, the application can also look up its transaction ID and confirmation count.

How to Try It

The current version is suitable for experimenting with wallet valuations, market-price displays, and historical lookups in an isolated environment. Approval for live market use, seven days of calibration, and a subsequent fourteen-day quote-observation period are still pending. The current version must not be used for real collateralization, borrowing, or liquidation.

For a first trial, start with the sample wallet balances above. Obtain the test environment's HTTPS address and CA certificate from the deployment administrator, and acquire the signature-verification configuration through a separate trusted channel. Then follow the manual to request a TBC/USD snapshot, verify its signature, and calculate the dollar price using the two underlying quotes returned. For step-by-step instructions, see the Quote API User Guide included in the deployment package.
